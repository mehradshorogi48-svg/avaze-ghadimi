# آواز قدیمی — Expo
این نسخه برای EAS Build آماده شده است.
برای ساخت APK:
`eas build -p android --profile preview`
پروفایل preview عمداً `android.buildType=apk` دارد تا فایل نصب مستقیم اندروید ساخته شود.
آهنگ‌ها در این نسخه نمونه‌اند؛ فایل‌های صوتی خودتان را می‌توان بعداً به پروژه و پخش‌کننده واقعی اضافه کرد.
